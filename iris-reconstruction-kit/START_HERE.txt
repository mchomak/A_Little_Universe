IRIS RECONSTRUCTION KIT v1.3
============================

1. Открой терминал в ЭТОЙ папке.
2. Выполни: python -m pip install -r requirements.txt
3. Запусти: python run_iris.py "C:\Photos\eye.heic" --interactive
4. В окне: o (точечный ВНЕШНИЙ контур: 1-й клик центр, потом 12-24 края, c),
   k (точечный ЗРАЧОК, аналогично); p/i = простые 2-кликовые круги.
   x / Shift+X (красным исключить кожу/ресницы и темные ресницы ПОВЕРХ радужки),
   s / Shift+S (голубым отметить видимую часть в тени),
   c (завершить многоугольник), v/n (исправить маску), Enter (экспорт).
5. Открой outputs/<имя фото>/contact_sheet.jpg.
6. Текстуры: iris_authentic_rgba.png, iris_cinematic_rgba.png,
   полный глаз: full_eye_composite.png + full_eye_foreground_rgba.png.
7. Повторное использование разметки: --annotation outputs/<name>/annotation.json

ПОЛНАЯ ИНСТРУКЦИЯ: README_RU.md

ПРИМЕЧАНИЕ: восстановление скрытой радужки — художественное, а не точная
биометрическая реконструкция. Full Eye — статические фото-ассеты, не 3D rig.


НОВОЕ В 1.3
- В редакторе нажмите O (маленькая латинская o) для внешней радужки:
  первый клик = центр, следующие 12-24 клика = точки вдоль края, C = сохранить.
- K (маленькая латинская k) — такой же режим для зрачка.
- P/I — старые круги двумя кликами.
- X маленькая латинская — исключить В ТОМ ЧИСЛЕ ТЁМНЫЕ РЕСНИЦЫ
  ПОВЕРХ самой радужки: тень S их не удаляет.
- Новая версия импортирует annotation.json v1.2 через --annotation.
