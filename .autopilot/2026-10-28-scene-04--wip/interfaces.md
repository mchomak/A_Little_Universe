# Интерфейсы

## Границы, решённые в спецификации

| Модуль | Владеет | Выставляет | Прячет |
|---|---|---|---|
| Сцена 04 | геометрия, состояния и визуал перехода | компонент сцены, принимающий общее время; минимальный заменяемый источник начальных частиц (координаты, идентичность и цвет в согласованной системе) | алгоритмы генерации, интерполяции, ASCII и жизненный цикл ресурсов |
| Film Runtime и directors | порядок, единые часы, камера и переходы | существующие контракты времени, управления и назначения сцены | детали управления состоянием других сцен |
| Галерея 05 | начальная поза и интерактивная навигация | согласованное начальное расположение первой карточки и камеры | последующее исследование галереи |

Проверять на существующих публичных швах времени и сцены, дополнительно контракт источника и границу 04→05. Имена конкретных типов следуют реальному коду; не создавать дополнительные абстракции без необходимости.

## Правила проекта

React + TypeScript + Vite, Three.js/R3F, один постоянный canvas и общие часы. Команды из `frontend/`: `npm ci`, `npm run check`, `npm run dev`. Не затрагивать другую сессию и сцены 00–01; не добавлять скрытую запись, отправку или персональные данные. Если необходимой зависимости нет, вернуть BLOCKED, не устанавливать её без согласования с оркестратором. Исходная фотография важнее изменённых черт на референсе.
