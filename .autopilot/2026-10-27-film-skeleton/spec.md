# Спецификация: сквозной каркас

## Задача
Пройти историю от кнопки начала через девять сцен до завершения на существующем React/TypeScript/Vite/R3F/GSAP. Все изображения и художественные объекты являются явно обозначенными development placeholders. Не создавать вымышленные воспоминания, фотографии или личное письмо. Backend, AGENTS.md, storyboard, зависимости и lockfile сохраняются.

## Сценарий и приёмка
1. Пролог: точка и утверждённые фразы «Я долго думал, что тебе подарить…», «И решил, что ты заслуживаешь чего-то особенного:». Обе фразы исчезают до приглашения прикоснуться к точке. 16 секунд затем неограниченное ожидание прикосновения.
2. Рост: 23 секунды; точка превращается в отдельное семечко 0–4, падение семечка 4–7, пробуждение 7–11, стебель/бутон 11–18, завершение 18–23. Автоматически входит в 03 с закрытым бутоном.
3. Раскрытие: ожидание прикосновения без ограничения; доступная DOM-кнопка и касание 3D-бутона. После действия 22 секунды анимации, полное раскрытие к 16, созерцание до 22. Камера поднимается с небольшим облётом на 45° сверху. Фразы сценария о прикосновении. Нельзя пропустить ожидание таймером.
4. Морфинг: 34 секунды; цветок 0–4, частицы 4–8, ВАСИЛИСА 8–13, переход 13–17, явно подписанный портрет-placeholder 17–23, фотография-placeholder 23–34 и «С этого всё началось» 28–34. Никаких поддельных лиц.
5. Галерея: шесть явно нумерованных placeholders на разной глубине, нейтральные подписи без событий. Кнопки назад/вперёд, свайп вертикальный, касание карточки для фокуса; допустим pinch. Плавное централизованное движение камеры и остановка для неограниченного чтения. Переход к глазу только отдельной кнопкой после достижения последней фотографии. Таймер и обычные события завершения галерею не покидают. На финальном повторном посещении можно вернуться к экрану завершения.
6. Глаз: 18 секунд, голубая радужка, указатель/касание только имитируют взгляд. Приближение камеры 15–18; переход всегда по времени. Не использовать неутверждённые личные фразы о глазах.
7. Космос: 26 секунд, радужка 0–5, частицы/спираль 5–11, пространственная спираль 11–15, простой букет из условных лилий/пионов 15–22, завершение 22–26; камера отдаляется и немного обходит композицию.
8. Поздравление: заголовок «С днём рождения, Василиса!» и «Пусть в твоей жизни всегда будет место для чего-то по-настоящему волшебного». Около 12 секунд на появление, затем медленные перспективные титры (до 50с общего времени). Временный текст честно помечен. Касание/кнопка паузы, обычное чтение в любой момент; чтение не продолжается автоматически. После титров ждать явной кнопки завершения. При повторном чтении из конца закрытие возвращает в конец.
9. Конец: полный перезапуск, галерея, обычное чтение поздравления.

Оформление всех сцен: фон #080914, палитра storyboard (жемчужно-розовый #F4CDD9, ivory #FFF0E8, lavender #B9A4E8, iris #54B4F0), системный serif для крупных фраз и sans для controls, мягкие fade/camera transitions. Маленькая голубая частица #54B4F0 — сквозной мотив; единый объект или согласованные позиции по сценам. Никаких дополнительных художественных эффектов без keyframes.

Документация обязана объяснить сценарный движок (состояния, gates, единые часы), добавление новой сцены (config/reducer/module/director/tests), замену placeholder финальной геометрией без изменения публичного контракта и подключение реальных ресурсов.

## Границы и швы
- `engine/filmConfig.ts`: SCENE_ORDER, SCENES, TIMING, COPY, MEMORIES; единственный источник длительностей/cues и утверждённого текста.
- `engine/film.ts`: типизированные FilmState, FilmAction, filmReducer. Единственный владелец навигационных разрешений. Публичный шов тестов — reducer и его действия. Время в секундах; revision защищает от устаревших callbacks.
- FilmState: scene: SceneId; mode: 'ready'|'playing'|'waiting'|'exploring'|'ended'; elapsed:number; paused:boolean; speed:number; revision:number; galleryIndex:number; reading:boolean. Дополнительные поля допустимы с описанием.
- Actions: start, toggle-pause, replay, interact, gallery-step(direction:-1|1), gallery-focus(index:number), gallery-exit, open-gallery, open-reading, close-reading, finish, timeline-update(time:number,revision:number), timeline-complete(revision:number), dev-jump(scene:SceneId), dev-restart, dev-skip, set-speed(speed:number), dev-seek(time:number). DEV действия принимаются только при явном флаге второго параметра/фабрики, production UI их не отправляет.
- `engine/useFilm.ts`: React hook useFilm() возвращает {state, dispatch, runtime}. Один scoped GSAP timeline управляет часами; останавливается на pause/reading/hidden, имеет timeScale. Обновляет state не чаще ~10 раз/сек, но runtime передаёт точное время подписчикам на каждом кадре. Никакого React state для частиц. Cleanup убивает GSAP context, снимает visibility listener. Hidden не меняет ручную паузу.
- `engine/runtime.ts`: FilmRuntime {time:number; subscribeFrame(listener:(time:number)=>void):()=>void}. Реализация может иметь publish(time) с отдельной фабрикой. Стабильный runtime на lifetime фильма. useSceneTimeline строит paused GSAP timeline в context, подписывается на runtime, выставляет time(runtime.time), cleanup unsubscribe+revert. Существующий hook переиспользуется/расширяется, а не дублируется.
- Scene props: {state:FilmState; dispatch:Dispatch<FilmAction>; runtime:FilmRuntime; reducedMotion:boolean}. SceneDirector выбирает модуль, key scene:revision даёт lifecycle. Девять модулей под scenes/, shared primitives допустимы. Сцены не создают Canvas/renderer и не меняют глобальную камеру.
- CameraDirector получает те же props, единственный владелец camera position/lookAt/fov. GSAP timeline синхронизирован runtime; gallery-index движение имеет отдельный scoped GSAP tween, учитывает pause/speed/reduced motion и cleanup. Portrait framing.
- FilmCanvas сохраняет GraphicsBoundary/GraphicsFallback/context-loss cleanup, demand rendering, один Canvas. Два качества (DPR/число частиц), defaults с лимитами. SceneDirector и CameraDirector внутри Canvas. Никаких внешних runtime assets в scaffold.
- App/UI: начальный экран с кнопкой, минимальные overlay prompts, синхронизированные с elapsed, панель галереи/чтения/финала, доступные controls. useReducedMotion сохраняется; reduced motion ограничивает движения, но не блокирует story clock. DevPanel lazy import только внутри import.meta.env.DEV, открывается ?debug или dev-кнопкой в любой момент. Scene select/run/restart/pause/speed/skip/state/FPS/interaction/seek. Production bundle не содержит панель и её тексты.
- Assets: честный manifest без обязательных внешних ресурсов на этом этапе; загрузку/ошибки Canvas показывает существующая граница. Статические импорты сцен до старта позволяют после загрузки пройти offline; persistent offline reload не обещается.

## Проверки
Reducer: весь маршрут, timed transitions, gates, gallery bounds/no timer exit, replay/direct dev jumps/speed/seek, pause/reading, stale revision rejection. Runtime/timeline: подписка/отписка и cleanup, StrictMode. Browser: сквозной accelerated route, реальные касания/кнопки, pause, gallery swipe, reading, replay, viewport landscape/portrait, production без DEV, offline после загрузки. npm test, typecheck, lint, build.

## Решения по объёму
ASSUMPTION: шесть нейтральных карточек; письмо временное без выдуманных личных фактов; титры 50 секунд с обязательной ручной кнопкой завершения; reload начинает сначала и история не добавляет browser history entries. Audio, настоящие ассеты, tracking/recording/upload, persistent offline cache — последующие задачи, согласно запретам брифа. Флаг reduced motion не ускоряет часы и не снимает interaction gates. Документация поясняет замену геометрии и добавление ресурсов. Весь модуль на существующих версиях, без новых библиотек.
