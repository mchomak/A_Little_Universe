# Интерфейсы

Один исполнитель владеет существующим Lily VFX, Scene Config и DEV-панелью с относящимися к ним тестами и документацией. Не изменять GLB, камеру, другие сцены или частицы. Сохранить вход effect.update и clipTime как источник истины. Существующие сохранённые настройки должны мигрировать безопасно. Команда полной проверки: npm run check из frontend/. Не добавлять зависимости. Перед первым изменением прочитать prompts/executor.md.
