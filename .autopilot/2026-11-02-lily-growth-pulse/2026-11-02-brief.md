# Изначальная задача

Продолжай работу в той же worktree и в той же ветке, где ты дорабатывал Lily Growth Particles. Новую ветку не создавай.
Задача
Сделай P0-доработку сцены роста лилии: добавить световой импульс вдоль стебля в сцене роста Lily 004.
Сейчас частицы уже есть, но самого ощущения, что рост “идёт изнутри” по стеблю вверх, почти нет. Нужно добавить хорошо читаемый, но деликатный световой импульс, который визуально проходит от основания цветка вверх вдоль стебля и подчёркивает живой магический рост.
Что нужно сделать
1. Световой импульс вдоль стебля
Добавь эффект мягкого светового импульса, который:
- рождается у основания цветка;
- движется вверх вдоль реальной геометрии стебля;
- синхронизирован с фазой роста Lily 004;
- визуально подчёркивает активную зону роста;
- оставляет короткий мягкий затухающий след;
- не превращает весь стебель в постоянную неоновую трубку.
Импульс должен быть заметен в обычном просмотре, но оставаться элегантным и не кричащим.
2. Поведение импульса
Нужно, чтобы импульс:
- был особенно заметен в момент активного роста стебля;
- кратко усиливался в зоне появления листьев;
- мягко усиливал свечение в зоне бутона, когда рост доходит до верхушки;
- корректно работал при обычном проигрывании сцены, при повторном запуске и при перемотке timeline.
Если сейчас в сцене уже есть зачаток такого эффекта, не делай вторую отдельную систему, а доработай существующий подход.
3. Новые настройки в DEV-панель
Добавь в DEV-панель отдельную группу, например Lily Growth Pulse или аналогичное понятное название.
Нужны рабочие настройки:
- Enable Pulse
- Pulse Intensity
- Pulse Width
- Pulse Speed
- Trail Length / Fade
- Pulse Color / Tint
- Leaf Boost
- Bud Boost
Если по реализации понадобится ещё 1–2 параметра — можно добавить, но без перегруза.
Все параметры должны:
- работать в реальном времени;
- быть подключены к Scene Config / DEV Editor в текущем стиле проекта;
- сохраняться и корректно переживать перезагрузку, как остальные параметры сцены.
4. Ограничения
- Не менять GLB-модель.
- Не трогать камеру без необходимости.
- Не переделывать частицы заново, кроме минимальной интеграции с новым импульсом, если это нужно для красоты.
- Не делать лишний рефакторинг.
- Не затрагивать другие сцены.
- Сохранять визуальную совместимость перехода 02 → 03.
Критерии результата
Результат считается удачным, если:
1. При росте визуально читается, что энергия проходит снизу вверх по стеблю.
2. Эффект делает рост живее и магичнее, но не выглядит как грубый sci-fi неон.
3. Импульс хорошо заметен на фоне текущей сцены.
4. Leaf/Bud зоны получают деликатный локальный акцент.
5. Новые параметры реально работают через DEV-панель.
6. Перемотка timeline и повторный запуск сцены не ломают эффект.
Проверка
После изменений:
- проверь работу в dev-режиме;
- проверь обычное воспроизведение;
- проверь seek/scrubbing в timeline;
- проверь, что эффект не исчезает/не зависает некорректно;
- запусти npm run check из frontend/.
Завершение
Когда закончишь:
1. Сделай commit.
2. Сделай push в ту же рабочую ветку.
3. Не делай merge в main.
4. Запусти сайт на отдельном порту, чтобы я мог посмотреть результат.
5. В финальном отчёте напиши:
 - какие файлы изменил;
 - какие параметры добавил в DEV-панель;
 - какой commit hash;
 - статус push;
 - на каком порту запущен сайт.
