## Критерии приёмки
- Материалы в runtime сохраняют maps, GLB геометрию/анимацию и dissolve hook, выразительно улучшают бутон/листья без пластика/неона.
- Все четыре DEV-группы и каждый параметр брифа в typed config/defaults/normalization/import/export/reset/storage. Live и paused uniforms применяются сразу; поля для частиц будут потреблены таском 02.
- Обратная совместимость v1–v14 и новые поля проходят тесты, остальные сцены/defaults не изменены.
- Материалы правильно обновляются при перемотке/смене сцен, собственные ресурсы/подписки dispose; shaders реально компилируются.
- Relevant tests + full npm run check green; приложить короткий контракт для particle worker.
