# Итог: Фон phone_1 в начальных сценах

## Решения, принятые за вас

| Решение | Почему |
|---|---|
| «До галереи» включает загрузку 00, подготовку 00.1 и сцены 01–04; фон отключается с галереи 05. | Так изображение участвует во вступлении, а галерея сохраняет собственный художественный фон. |
| Кадрирование настраивается в существующей DEV-панели и сразу меняет общий профиль. | Не требуется новый интерфейс настроек или отдельный renderer. |
| Масштаб и смещения можно сохранить через существующий JSON export/import; production может загрузить optional `scene-composer.json`. | Используется текущий путь Composer и не добавляется автоматическое браузерное хранилище. |

## Готово

- `images/phone_1.png` отображается на экранах 00/00.1 и в сценах 01–04; при переходе в галерею 05 слой исчезает, фон галереи остаётся собственным.
- В DEV Scene Editor доступны live-параметры масштаба (1–3) и X/Y смещения (−1…1), а также сброс к центру. Изменение проверено в браузере.
- Scene Composer schema v15 хранит профиль; частичные JSON schema v14 продолжают импортироваться с новыми значениями по умолчанию.
- Полная проверка проекта прошла: lint, typecheck, production build, 98 файлов и 477 тестов. Сборка включает `phone_1` как optional offline-cache asset.

**Запустить:** из PowerShell в корне проекта — `Set-Location .\frontend; npm run dev`. Открой URL из вывода Vite и добавь `?debug`, затем найди в DEV Scene Editor секцию «00–04 · Кадрирование фона». Значения действуют в текущем процессе; для переноса используй JSON export/import.

## Открытые вопросы

- Слепой независимый запуск смог проверить экран подготовки и DEV-контролы, но пометил проверку сцен частичной: его браузер сообщил об отсутствии WebGL2, а свободные порты 5173 и 5174 были заняты. Координатор проверил в уже открытом Chrome: сцены 01–04 содержат загруженный фон, а сцена 05 его не содержит и сохраняет собственный вид. Физический MacBook M2 не проверялся.
- Production build прошёл с существующими предупреждениями Vite о загрузчике конфигурации и размере одного из чанков.
- В Scene 01 фото заменяет утверждённый почти чёрный keyframe, как следует из запроса; storyboard и исходный keyframe не менялись.
- Интерактивный Autopilot dashboard-сервер не стартовал в Windows: скрипт использует POSIX `ps`. Снимок dashboard обновлён командой `python .autopilot/sync.py --no-serve`.
