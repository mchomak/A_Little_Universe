# Спецификация: phone_1 как фон начальных сцен

## Задача

Пользователь хочет увидеть выбранное изображение phone_1 за сценами перед галереей и самому подобрать, какая часть изображения попадёт в кадр.

## Решение

Показывать phone_1 как статичный фон экранов и сцен от загрузки 00 до runtime-сцены 04. В существующем DEV Scene Editor добавить настройки масштаба и положения фона с обновлением кадра сразу во время просмотра. Выбранные значения входят в общий Scene Composer config, поддерживают экспорт/импорт JSON и применяются при production-запуске из его optional startup config. Галерея 05 и следующие сцены сохраняют свои текущие фоны.

## Решения по реализации

- Использовать существующий React/TypeScript, Scene Composer store и DEV Scene Editor. Изменения live-просмотра находятся в памяти процесса; пользователь сохраняет выбранный профиль существующим JSON export/import, а production опционально загружает startup JSON. Не добавлять зависимости, автосохранение в localStorage и отдельное хранилище настроек.
- Ввести один общий профиль кадрирования для сцен 01–04: `zoom` (по умолчанию `1`, диапазон `1–3`), `offsetX` и `offsetY` (по умолчанию `0`, диапазон `-1…1`). Значения нормализуются и ограничивают смещение так, чтобы на краях кадра не появлялись пустые полосы.
- Кадрировать изображение по правилу `cover`, исходное положение — по центру. Масштаб, X и Y меняются только пользовательскими событиями; не создавать per-frame React state updates.
- Размещать один статичный image layer под содержимым экранов 00/00.1 и под persistent WebGL Canvas в сценах 01–04. Сделать прозрачными только сплошные фоны внешних контейнеров загрузки и подготовки, сохранив сами индикаторы, карточки и тексты поверх изображения. У Canvas убрать цветовой фон только на сценах 01–04; камера и film clock остаются у текущих владельцев. Фон не создаёт отдельный renderer и не следует за движением камеры.
- Включать слой на экранах 00/00.1 и runtime-сценах 01–04. Применять тот же crop-профиль по всему этому вступлению; отключать его при входе в галерею 05.
- Подключить image как локальный runtime asset, включённый в production bundle и доступный offline; `images/phone_1.png` оставить нетронутым.
- Добавить настройки в версионируемую схему Scene Composer с совместимостью с предыдущей schema v14 и её существующими частичными JSON.
- При ошибке декодирования оставить штатный тёмный фон `#080914`; загрузка основного фильма и остальные сцены продолжаются.

## Границы и швы

| Модуль | Владеет | Выставляет | Прячет |
|---|---|---|---|
| Scene Composer config | нормализованными общими значениями масштаба и crop | существующие `getConfig` / `updateConfig` и config JSON | диапазоны, значения по умолчанию и миграцию старых schema |
| Слой фона фильма | ресурсом phone_1 и отображением до сцены 05 | текущий route/scene и параметры crop из общего config | `cover`, ограничение смещения и детали DOM/CSS |
| DEV Scene Editor | доступными настройками zoom/X/Y и сбросом | обновления через существующий config store | способ рендера фонового слоя |

Швы тестирования: нормализация и миграция config проверяются на публичной границе `normalizeConfig`; видимость слоя и DEV-контролы — через существующие React testing seams. Финальная проверка дополнительно проходит браузерный просмотр сцен 01–05.
