# Границы

Одна связная художественная доработка, исполнитель владеет материалом воды и необходимыми сценовыми настройками/тестами/документацией. Общие camera, timeline, canvas, сцены вне 05 и геометрия не меняются. Текущий renderer и planar capture переиспользуются. Команда проверки: `cd frontend; npm run check`. Локальный сервер: `npm run dev -- --port 5186`.
