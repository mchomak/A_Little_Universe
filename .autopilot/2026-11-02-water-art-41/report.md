# Приёмка

Пол получил тёмную navy основу, независимую силу и затухание отражений, мягкую тональную компрессию отражённого окружения, микронормали на нескольких масштабах и локальный серебристо-голубой блик с положением по данным луны и камеры. Planar pipeline и общая геометрия сохранены. Новые ручки: яркость основы, затухание, масштаб микроискажения и ширина лунного блика.

Defaults: базовая яркость 0.72; сила отражений 0.5; blur 0.52; falloff 1.25; distortion 0.008; micro scale 1; ripple speed 0.12; normal strength 0.22; moon highlight 0.92; moon spread 1.15; opacity 1. Schema v13 сохраняет явно заданные значения v12, отсутствующие поля получает из defaults.

Проверки: npm run check — lint,432 tests/91 files,TypeScript,production build прошли. Chromium1440×900: начало, середина, фокус, вперёд/назад, сила отражения=0 и возврат; ошибок console/WebGL не выявлено. Непрерывная длительная проверка мерцания и измерение на MacBook M2/Safari не выполнялись. Доступного нового вложения не было; сравнение проведено по saved final-start.png предыдущего этапа и approved K05-01.

Ограничение ревью: при экстремально пологом направлении луны к цели (например moonY16,targetY14) ограничение параметра пересечения может сместить начало дорожки; значения по умолчанию не затронуты. Указанные ориентиры и точную художественную яркость можно продолжить настраивать в Dev Panel.
