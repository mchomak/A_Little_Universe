# 05 — Арка завершает раскрытие

**Требования:** R09, R14–R15, R18–R22
**Blocked by:** 02, 03, 04
**Зона:** Gallery arch visual layer и итоговая приемка handoff
**Волна:** 3
**Status:** ready

## Что должно заработать

Арка появляется последней, когда уже проявились вода, атмосфера, лунный свет, все колонны и фотографии, включая фото без опоры. После её fade сцена целиком раскрыта, начинается текущее движение портрета, затем появляется памятка. Дать краткое подтверждение фактического поведения последнего фото и подготовить проверочный запуск сайта.

## Разделы спецификации

Истории 4, 6 и 8; решения «Временная модель», «Визуальные слои»; вне рамок R07.

## Критерии приёмки

- [ ] Арка остаётся невидимой пока не завершены все этапы колонн и фотографий, включая фото без опоры; затем появляется плавно и достигает штатного `archOpacity` с сохранением distance fade.
- [ ] Никакой другой слой не начинает alpha transition одновременно с аркой; она закрывает последовательность строго после последнего элемента, включая фото без опоры.
- [ ] После её завершения контроллер запускает старый сдвиг первой фотографии, а памятка появляется уже после него, с прежним dimming, стилем и reduced-motion поведением.
- [ ] Проверено, что выбор последнего фото сам по себе не завершает галерею: завершение остаётся через возврат в прогулку и отдельный клик «Продолжить». Существующая логика не меняется.
- [ ] Production build проходит; запуск на свободном отдельном localhost-порту не останавливает другие процессы.
- [ ] Изменения попадают только в commit для текущей `main`; после проверки пользователь получает URL, ветку и commit hash.
