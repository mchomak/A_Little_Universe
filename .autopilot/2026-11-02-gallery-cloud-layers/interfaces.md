# Границы
Исполнитель владеет сценовыми clouds/world/material и дополнениями scene-config/DevPanel, тестами и docs. Вода, фото, камера и единый FilmCanvas вне зоны изменений. Старые импортированные параметры и настройки воды сохраняются. Параметры слоя различаются по названию, без дубликатов. Gallery runtime использует galleryMotion.time, а render loop остаётся общим. Проверка: frontend npm run check. Визуальный просмотр: http://127.0.0.1:5187/?debug.
