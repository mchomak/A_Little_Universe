## Самобрифинг (режим `full`)

- Все проектные документы из R05–R11 доступны локально; исходный v1.1 и reference folders являются основанием по 02–09.
- Состав списка шрифтов ограничивается реально доступными локальными файлами с доказанной кириллицей; Manrope остаётся интерфейсным шрифтом.
- Live preview должен действовать только через существующий film runtime и одну общую конфигурацию. Сцена 00.1 меняет только визуальные CSS-параметры; реальные permissions/load progress остаются вне художественных контролов.
- Для запуска production-сайта разумно предусмотреть конфигурацию из локального JSON ресурса, объединяемую с defaults; ошибки этого optional resource не блокируют загрузку.
- Для сцены 01 приоритет — детерминированное отображение из времени таймлайна (seek/replay), а не локальная физическая симуляция.
- Физический iPad недоступен в этой среде; проверяются браузерные viewport и GPU-сценарии, а реальное устройство будет явно указано как ограничение.
