# Приёмка

- Утверждённый export из portret_2: 32 000 точек преобразованы в бинарный ресурс 1 536 020 байт с координатами, типом и визуальными атрибутами. Независимое сравнение всех записей: максимальное отклонение float32 9.54e-8; контрольные суммы исходника и ресурса совпадают с метаданными.
- Все 113 ручных contour сохраняются, когда позволяет бюджет. Остальные точки выбираются по всей упорядоченной композиции; траектории вихря остаются прежними. Seed внешнего вида плавно меняется при посадке, seed траекторий прежний.
- Время удерживается до готовности данных и геометрии; при ошибке загрузки предлагается повтор. Тесты контроллера покрывают задержку, ошибку, retry, seek и unmount, а также shader substitutions.
- npm run check: ESLint, 457 тестов в 96 файлах, TypeScript и production build прошли. Страница и бинарный ресурс на 127.0.0.1:63797 отвечают HTTP 200.
- Независимый обзор подтвердил закрытие замечаний по загрузке, контурам и seed; сравнение каждого байтового поля проведено отдельно.
- Визуальная приёмка и прямое воспроизведение/seek в браузере не выполнены: профиль инструмента Playwright уже занят, а управление браузером Windows остановлено инструментом из-за невозможности надёжно определить текущий URL. Тесты контроллера не являются проверкой React commit или WebGL в браузере.
