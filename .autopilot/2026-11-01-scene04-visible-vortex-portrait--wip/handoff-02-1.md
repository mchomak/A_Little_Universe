## РЕШЕНИЯ
- Код изменён только в `frontend/src/scenes/lily/dissolve.ts` и `frontend/src/scenes/lily/dissolve.test.ts`; runtime-подключение в таске 03 ещё не сделано, `LilyDissolveParticles.tsx` и `AnimatedLily.tsx` не менялись.
- Новый `LilyVisiblePortraitGeometryOptions`: `targets: readonly StarPortraitPoint[]`, `targetPositions`, `cameraBasisAtTime(time): PortraitCameraBasis`, `capture: LilyPortraitCaptureSettings`; legacy-ветка с `PortraitTarget[]` и статическим `cameraBasis` сохранена для DEV-лаборатории.
- `LilyPortraitCaptureSettings`: `portraitStartProgress`, `portraitFraction`, `portraitMinTurns`, `portraitMaxTurns`, `portraitSteering`, `portraitBraking`, `portraitSettledBrightness`, `vortexSpeedMultiplier`.
- Планировщик за один проход вычисляет индивидуальные launch time из порога распада, отсоединения, джиттера и витков; проверяет fade и проекцию именно через `cameraBasisAtTime(launchTime)`, отбрасывает скрытые/закадровые точки, сортирует кандидатов по времени и назначает не более `min(targets, targetPositions, floor(count * fraction), visibleCandidates)`. Поиск не является O(N×targets); при нехватке кандидатов геометрия не подменяет их невидимыми.
- CPU и GLSL используют `uLilyVortexSpeedMultiplier`; добавлены uniforms `uLilyPortraitSteering`, `uLilyPortraitBraking`, `uLilyPortraitSettledBrightness`, атрибут `aPortraitSeedData`, RGB записывается в `aPortraitSourceColor`. CPU-зеркало: `getLilyParticlePortraitPosition(route, time, source, settings, controls?)`; маршрут использует стартовую скорость вихря, Hermite-посадку и абсолютное время.
- Тесты: `cd frontend; npm test -- src/scenes/lily/dissolve.test.ts` — 13/13, было 10; `npm run check` — exit 0. Полный baseline был 347 тестов; число после изменений не сохранилось в обрезанном выводе `Select-Object -Last 30`.
