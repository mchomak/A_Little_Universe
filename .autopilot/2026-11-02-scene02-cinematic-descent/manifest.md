# Scene 02 — требования

Задача пользователя: этапы 02–04, продолжение в `codex/scene02-floating-island`. Предшествующее состояние `.autopilot/state.js` относится к другому прогону и сохраняется.

| ID | Требование | Проверка |
|---|---|---|
| R01 | Строго вертикальный центральный лунный луч, выразительная мягкая объёмная атмосфера, влияние на материалы и тени | Геометрия источника, браузерные кадры, тесты |
| R02 | Органичное формирование семечка из частиц с асимметричными наклонёнными орбитами и ростом яркости/размера | Формирование, повтор и перемотка |
| R03 | Более длительное пространственное падение, задержка камеры, след и плавное появление острова | Timeline и визуальная проверка |
| R04 | Независимые объёмные облака с параллаксом, по мотивам сцены 05; центр лилии свободен | Визуальная проверка и изоляция сцены 05 |
| R05 | Центральная посадка, мягкий импульс, искры и плавная передача существующей GLB-лилии | Кадры контакта и роста |
| R06 | DEV-параметры света, семечка, падения, облаков и посадки; сохранение существующих настроек | Миграция и проверка каждого регулятора |
| R07 | Общие canvas, SceneDirector и CameraDirector, соседние сцены и существующая анимация лилии сохранены | Тесты и независимое ревью |
| R08 | Полная сцена, перемотка, повтор, WebGL и production build | Автоматические проверки и браузер |
| R09 | Commit и push в существующую ветку, перезапуск сервера и проверенный URL; без PR/merge | Git и HTTP |

Предположение: отдельный скриншот не передан в доступном контексте; референс текущего результата — запущенная сцена этой ветки.

Приёмка R01–R08 выполнена; R09 выполняется при публикации. Ограничение: лунная дымка использует непрерывную аналитическую плоскость, а не depth-aware объём; мягкая контактная тень не является динамической shadow map от цветка и травы. Камера сцены 03 получает конечную позу сцены 02 для непрерывного перехода.
