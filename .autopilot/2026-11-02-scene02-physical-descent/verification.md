# Проверка

- `npm run check`: ESLint, 93 файла тестов / 462 теста, TypeScript и production build прошли. Существуют предупреждения Vite о config loader и большом чанке, а также предупреждение Three.js о CommonJS.
- Chromium, WebGL через SwiftShader, 1200×900 (4:3): последовательность проиграна до сцены 03; проверены кадры формирования, падения, входа острова, посадки и завершённого роста. Проверены перемотки в обоих направлениях и пауза; ошибок консоли и `pageerror` не обнаружено.
- Изменены в DEV и проверены все пять полей движения. Сохранённая конфигурация v15 с явно указанными 2,6 с сохраняет это значение; для новых конфигураций — 3,6 с.
- Независимое ревью: рост, контакт, непрерывность камеры и reduced motion проверены по коду; блокирующих замечаний нет.
- Фактическую производительность на Apple M2 в этой среде не измеряли. Отдельное изображение, названное в брифе приложенным, в доступном контексте отсутствовало; композиция проверялась по работающей сцене.
