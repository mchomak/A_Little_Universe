# Тонкий слой воды — сцена 05

## 1. Результат
Визуальные критерии: пол явно читается как тонкий слой воды, приближает ощущение сцены к approved K05, сохраняет общую композицию и геометрию галереи. Не идеальное зеркало, не бассейн/море, без сильной волны; деликатный кинематографичный вид. Отражение луны включает вертикальный световой блик.
Текущая геометрия пола, фотографии, облака и луна остаются в своих координатах. Пол получает настоящий planar reflection pass с виртуальной камерой от текущей камеры фильма. Отражаются реальные фото, луна/halo и слабый облачный контекст. Прежние фото-прокси скрываются/удаляются из активного пути, чтобы исключить двойное отражение.

## 2. Материал и отражения
Отдельный сценовый модуль воды использует существующий WebGLRenderer, не создаёт Canvas/собственный clock. Ориентиры: Three Water.js (папка локально three.js) и Drei MeshReflectorMaterial + его документация. Отражённая камера зеркалится относительно floor.y; oblique clip plane отсекает подводную половину сцены, сам пол исключается во время capture. Все изменённые состояния renderer и visibility восстанавливаются через finally; рекурсия запрещена. Материал хранит navy/blue-black основу, слабый Fresnel и roughness-like breakup, небольшую локальную лунную дорожку/specular. Пол остаётся плоским: микрорябь меняет normals/UV, без displacement. Использовать нормальную карту (можно процедурную DataTexture, без внешнего ассета); анимация читает galleryMotion.time и соблюдает паузу/reduced motion.

Reflection RT 1024 на standard; 2048 только если визуальное сравнение оправдывает стоимость; low может быть 512. HalfFloat при поддержке color buffer float, безопасный RGBA8 fallback. Мягкий blur (сэмплирование либо blur pass) сохраняет узнаваемость отражений; учитывать дистанцию/depth-like ослабление. Отражение мира следует live камере и фокусу. Материалы, targets и textures dispose при выходе, настройки не пересоздают targets каждый кадр. Существующий render loop сохраняется.

## 3. Параметры и совместимость
Сохранить reflectionStrength [0,0.6] и reflectionBlur [0.3,1] и их явные старые значения. Добавить gallery поля: waterDistortion [0,0.05] default 0.008; waterRippleSpeed [0,1] default 0.12; waterNormalStrength [0,1] default 0.22; moonHighlightStrength [0,2] default 0.7; waterOpacity [0,1] default 0.9. reflectionStrength default допускается поднять до 0.42 для читаемой воды, blur default 0.6; legacy явные значения сохраняются. Аддитивная schema v12, импорт v1–v11 дополняется новыми defaults. Обновить Dev Panel, экспорт/импорт/reset, документацию и meaningful тесты миграции/границ. Все семь регуляторов действуют live, в том числе на паузе.

## 4. Проверка и границы прохода
Проверить npm run check. Проверить браузером вход в галерею, движение, фокус/возврат, pause, reduced motion и low, переход из галереи/возврат без WebGL errors. Сохранить кадры начала и середины, подтвердить реальность отражений относительно камеры. Не заявлять производительность Apple M2 без измерения на устройстве. Этот проход создаёт визуально оцениваемую базу, точная художественная доводка ряби и бликов остаётся следующим проходом по запросу пользователя.
