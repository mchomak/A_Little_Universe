# Спецификация: Lily Magical Growth & Bloom

## Задача и решение
Лилия 004 сохраняет настоящий матовый цветок и исходную GLB-анимацию; добавляются живая ткань листьев, деликатный свет бутона, свободный восходящий вихрь и редкая светящаяся пыльца раскрытия. Источник художественных решений — Storyboard v3.0 §§02–03, существующая реализация и названные в брифе оттенки. Изображения S02/S03 доступны как визуальное направление; утверждение этих кадров в индексе не зафиксировано.

## Контекст
Отдельный worktree, строго ветка codex/lily-magical-growth-bloom от свежего origin/main (b70ac3bcb51ce022ebc6e71abc2d1c9f08486f2a). Другие worktree не меняются. React/TS/Vite/Three/R3F/GSAP сохраняются. Main содержит config v14, тогда как инструкции описывают v15 другой ветки: исходный контракт этой ветки расширяется совместимо, без переноса чужого кадрирования и других изменений.

## 1. Внутреннее свечение бутона
Как зритель, я вижу мягкий жемчужно-розовый внутренний свет; объём, матовая поверхность и детали остаются читаемыми. Runtime-патч клонированных материалов добавляет умеренный emissive, мягкий Fresnel и тонкие продольные акценты в UV/локальных координатах. Никаких новых мешей вместо лепестков и непрозрачной лампы. Сила растёт плавно к завершению Growth и равна старту закрытого Bloom, затем деликатно усиливается при раскрытии. При выключении свечение исчезает без разрушения исходного материала. Не менять dissolve-патч сцены 04; композиция shader hooks сохраняет его. Готовая открытая поза и материал переходят непрерывно в существующее растворение, новые эффекты не меняют поведение сцен 04–09.

## 2. Улучшение материалов листьев
Как зритель, я вижу мягкую зелёную вариацию, сдержанную подсветку краёв и имитацию света через тонкую ткань. Центральная жилка — тонкая UV или локальная модуляция цвета без изменения геометрии; при непригодных UV использовать локальные координаты, если это возможно. Без неона и пластика; сохраняются maps и анимация GLB. Воздействие материала листьев изолировано от стебля. Клоны и shader uniform cells имеют корректное освобождение; cached useGLTF материалы не мутируются.

## 3. Восходящий вихрь частиц во время роста
Как зритель, я вижу отдельный воздушный Growth Vortex возле активной верхушки роста. Его якорь берётся из фактически позированной GLB (деформированные вершины/узлы), не из фиксированной мировой высоты и не из приблизительной конечной высоты. Несколько свободных спиралей вокруг вертикальной оси растения идут по часовой стрелке сверху; разные seed определяют фазу, высоту, скорость, размер, яркость и смесь жемчужного, белого и шампанского с основным настраиваемым цветом. Нет мини-галактики и копирования portrait/transform системы сцены 04.

После полного завершения роста вихрь плавно расширяется, разлетается в стороны и вверх, одновременно уменьшается и гаснет в ноль за Dissipation Duration. Хвост не обрывается на 02→03 даже при длинной настроенной длительности; на gate время хвоста продолжает идти детерминированно. Обратная перемотка восстанавливает ровно то же состояние без накопленных частиц и RNG на кадр. Reduced motion уменьшает движение/плотность, не отключает понятную фазу магии.

Все исходные частицы роста, в том числе любые частицы возле листьев, остаются отдельно с существующими правилами; существующие core/pulse не пересоздаются и не меняются. Обнаружено, что на main есть seed core и sparks, но отдельный leaf/pulse модуль не найден: это наблюдение о доступной базе, а не отмена требования: проверка сохранения выполняется сравнением с base commit, отдельные новые core/pulse/leaf particles не создаются.

## 4. Магическое раскрытие лилии — Scene 03
Как зритель, я вижу постепенное появление мелкой тёплой жемчужно-золотистой пыльцы по мере реального открытия GLB. Якорь чаши/тычинок следует позированной модели и совпадает с ней при скраббинге. Разные seed дают глубину и яркость. Часть крупинок медленно поднимается над цветком с небольшим дрейфом и растворяется. Внутреннее мягкое рассеянное освещение акцентирует тычинки и основания лепестков, через локальную material-модуляцию без изменения глобального света/камеры. Центр не закрывается облаком, лепестки не пересвечиваются. Пик ближе к полному раскрытию; затем плотность падает до нескольких редких крупинок, спокойное открытое состояние сохраняется до 03→04. Остаток эффекта гаснет вместе с существующим handoff без изменения логики сцены 04.

## 5. Новые настройки DEV-панели
Использовать текущий Scene Config/DEV Editor: типы, defaults, normalization, import/export, reset и storage. Никакой параллельной конфигурации. Группы видимы и подписаны ровно:
- Lily Bud Glow: Enable (boolean), Glow Intensity (0–2), Glow Color (hex), Rim Strength (0–2), Bloom Boost (0–2).
- Lily Leaf Material: Translucency Strength (0–1), Edge Light Intensity (0–1), Color Variation (0–1).
- Lily Growth Vortex: Enable, Particle Count (0–1600 integer), Particle Size (0.2–8 px basis) / Variation (0–1), Brightness / Glow (0–3), Orbit Radius (0.02–1.5 world units), Rotation Speed (0–4 rad/s), Vertical Spread (0.02–2 world units), Spiral Tightness (0.1–6), Dissipation Duration (0.2–12 s), Dissipation Spread (0–3 world units), Particle Color (hex).
- Lily Bloom Pollen: Enable, Particle Count (0–600 integer), Particle Size (0.2–6 px basis), Glow Intensity (0–3), Rise Speed (0–0.5 world units/s), Spread Radius (0.01–0.8 world units), Lifetime (0.5–12 s), Inner Cup Glow (0–2).
Defaults: subtle glow, a few hundred vortex motes, tens of pollen grains; final values tuned against actual render. Particle size scales with DPR/perspective like existing points and is capped to avoid giant sprites. Every setting changes while running or paused, persists across reload and export/import, resets by existing scopes. Missing settings in old v1–v14 JSON receive fresh defaults; malformed/nonfinite values clamp/fallback. No lost existing values; schema bump and explicit compatibility tests.

## 6. Ограничения и проверки
Переиспользовать текущий point rendering/shader conventions и runtime clock. Новые частицы аналитические seeded absolute-time, небольшое число draw calls, typed arrays на ресурс, без per-frame React state. Прозрачные points additive/depthWrite=false и нормальный depthTest для корректного объёма; геометрия и материалы освобождаются при изменении count/unmount, clock subscriptions снимаются. Стабильная работа на MacBook M2 — целевой бюджет; измерение на текущем хосте не выдавать за тест на M2.

Не менять GLB, animation clips, камеру, глобальный свет, сцены 04–09. Общую persistent Lily разрешено интегрировать минимально ради новых материалов/эффектов и непрерывности; существующий dissolve не переписывать. Без новых тяжёлых зависимостей и необязательного рефакторинга.

Приёмка: обычное воспроизведение и touch gate; scrubbing назад/вперёд/повтор того же timestamp; restart; границы 02→03→04; эффект в начале/середине/конце роста и раскрытия; long dissipation; zero/disabled/count changes при pause; reduced motion. Визуально отсутствие резкого pop, квадратных point sprites, прозрачных плоскостей и белого clipping; отсутствие shader/browser errors и утечек GPU после повторов. npm run check из frontend обязателен (lint, tests, TS, build). Тесты на существующих границах normalization, timing и runtime material/particle evaluator; не тестировать копию формулы без проверки пользователя-видимого поведения.

|---|---|---|---|
| Existing Scene Config / DEV Editor | четырьмя группами настроек | typed config, normalization/store/import/export/reset | clamp/defaults/storage |
| Lily runtime material layer | клоны GLB-материалов, общие stable uniforms | compose material patch + update from scene pose/time/config | GLSL detail, resource cleanup |
| Lily magical particle layer | growth vortex/pollen, posed anchors, deterministic time | integration in persistent AnimatedLily using scene/runtime/config | seeded trajectories, point resources, tails |
Швы тестов: existing config public boundaries; pure time/anchor evaluator used by rendering; shader-patch composition. Persistent film runtime owns timing/camera/state; particles only read them.

## Вне рамок / открытые места
Нет отложенных требований, пользовательских placeholders, платных сервисов или новых функций сверх брифа. Уточнение: leaf-local particles and stem pulse отсутствуют в fetched main как отдельная система; все существующие эффекты сохраняем по сравнению с base commit; отсутствие отдельно названных систем честно указываем в отчёте, не создаём их заново.
