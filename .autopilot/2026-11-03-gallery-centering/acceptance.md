# Приёмка

Причина первого перекоса: опоры наследовали масштаб первой картинки вокруг левого центра. Причина неравного зазора при настройках DEV: X-координаты опор использовали общую ширину галереи, а фото использовали ширину и радиальный сдвиг своего B-ряда. Теперь обе координаты рассчитываются по одному ряду; Z-центры остаются посередине границ. Поворот фото и камера не менялись. Полный npm run check: 472 теста, lint, typecheck и production build.
