# Приёмка

Причина первого перекоса: опоры наследовали масштаб первой картинки вокруг левого центра. Причина неравного зазора при настройках DEV: X-координаты опор использовали общую ширину галереи, а фото использовали ширину и радиальный сдвиг своего B-ряда. Теперь обе координаты рассчитываются по одному ряду; Z-центры остаются посередине границ. Поворот фото и камера не менялись. Полный npm run check: 472 теста, lint, typecheck и production build.

После обратной связи выяснилось, что прежняя проверка Z учитывала якоря колонн, а видимые валы GLB были смещены от них. Теперь Z картины совпадает с серединой видимых валов с учётом масштаба и глубины; камера и нити используют тот же центр. Реальный GLB и проекция камеры проверены для обеих сторон, всех пар и разных значений настроек. Полный npm run check: 475 тестов, lint, typecheck и production build. Визуальную проверку WebGL на этом окружении выполнить не удалось.
