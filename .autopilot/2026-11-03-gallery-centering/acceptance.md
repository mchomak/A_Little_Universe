# Приёмка

Причина: первая пара опор в B наследовала масштаб первой картинки вокруг её левого центра, поэтому при ширине 7 м координаты колонн получались −3,5 и +5,95 м. Исправлены преобразования опор на протяжении интро; фото и камера не изменены. Тест Three.js проверяет мировые координаты при трёх стадиях интро; тесты варианта A, движения и фокуса проходят. Полный npm run check: 471 тест, lint, typecheck и production build. Доступный браузер не поддерживает WebGL2, визуальное сравнение с исходным скриншотом не выполнено.
