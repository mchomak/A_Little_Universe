# 04 — Интеграция с фильмом и DEV-панелью

**Требования:** R02, R17, R21–R22, R50–R57, R64–R90
**Blocked by:** 03
**Зона:** `frontend/src/app/`, `frontend/src/debug/`, `frontend/src/scenes/gallery/`
**Волна:** 3
**Status:** ready

## Что должно заработать

Приложение связывает MusicDirector с теми же стартом фильма, film state и событием выхода из галереи, что уже использует фильм. На localhost DEV-панель получает небольшой русский раздел «Музыка» с текущим треком, настройками и пробным переходом. Музыкальные поля остаются отдельно от сцено-конфига. Подключение не меняет камеру, переход, сцены, тайминг, фотографические переходы или существующий подготовительный поток.

## Из брифа, дословно

> «Запускать `In the Pool` после первого разрешённого пользовательского взаимодействия, которым запускается фильм.»
> «Не переключать треки при выборе очередной фотографии. Не перезапускать плейлист при фокусе на изображение.»
> «по событию начала выхода из последней фотографии планетария»
> «Добавь компактный раздел “Музыка” на русском языке.»

## Разделы спецификации

Истории 2, 4, 6–10; решения 1–5, 9, 13; границы DEV Music section.

## Критерии приёмки

- [ ] Один app-lifetime MusicDirector подключён к существующему `AudioDirector` и film lifecycle; первый Intro стартует непосредственно в разрешённом start gesture, новый экран/шаг не добавлен.
- [ ] Сцены 01–04, фото focus, фото selection, переход в cosmos/ending не создают второй director и не перезапускают текущий трек.
- [ ] Gallery phase exit последней planetarium-фотографии вызывает один финальный переход; возвратная галерея из ending исключена. DEV jump/skip/replay синхронизируют музыку по целевой группе.
- [ ] Компактная русская секция показывает toggle, общую громкость, fade scale, Intro/Outro offsets, intro/gallery/outro gains, текущий трек и позицию; preview следующего трека использует штатный fade.
- [ ] UI сохраняет настройки отдельно от Composer; в пользовательском режиме нет обязательных музыкальных настроек и новый экран не появляется.
- [ ] Интеграционные управляемые проверки покрывают первую gesture, state/group transitions, повторный вход в gallery, возврат из ending, reload/replay, current snapshot и DEV-настройки.
- [ ] Проверены фактическая загрузка MP3 в Vite DEV и production; отдельная production/offline/Electron smoke-проверка следует по возможности сборки. Нет ошибок загрузки доступных локальных MP3.
- [ ] `npm run check`, production build и музыкальные тесты запущены; существующие несвязанные lint errors перечислены отдельно и не маскируются.
- [ ] Готовая работа закоммичена в актуальный `main`, отправлена в `origin/main` без force push, локальный production-preview перезапущен; сдача содержит точный список использованных/неиспользованных MP3, файловый diff, offline-поведение, значения crossfade, результаты проверок, commit SHA и локальный URL.

## Ограничения

Не менять пользовательский `PreparationScreen`, запись/consent flow, визуальные сцены/эффекты, camera transition, film timings, музыкальные исходники или preset schema.
