# Interfaces

- Gallery arch placement derives from actual column model placements and a constant calibrated offset.
- Collage layout and focus camera use the same dimensions and texture aspects; camera fitting stays within the existing shared renderer.
- Composer schema v24 imports previous configurations and normalizes legacy short particle timings.
- The global SceneDirector, transitions and galaxy animation remain outside this work.
- `memorySignalBaselineDimensions` and `processMemorySignalBaselinePixels` provide the local photo-pixel sample; collage reveal geometry maps that sample into its aspect-preserving photo plane.
- The collage playback frame keeps particles visible and animated through the 3.5-second particle-only hold before setting progress for the scene 04 photo reveal.
