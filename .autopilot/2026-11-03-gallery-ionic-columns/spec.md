# Спецификация

Используется предоставленный GLB Sketchfab CC BY 4.0; файл загружается одним URL-кэшем, геометрия, текстуры и адаптированные материалы разделяются экземплярами. Колонна — потомок общего Memory anchor; подвижная фото-группа и колонна связаны симметричной шириной. Реальный GLB сам задаёт оси и матрицы; продляется только ствол, исходная капитель перемещается выше поля зрения. Материал холодный PBR, с обычным depthWrite; raycast колонны отключён.

Настройки schema v15: ширина, видимость, масштаб, глубина, смещения X/Y; старые конфиги получают defaults. Камера фокуса, световые нити и фото используют одну ширину. Без изменений main, воды и облаков.
