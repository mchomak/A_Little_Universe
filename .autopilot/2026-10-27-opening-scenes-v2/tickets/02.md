## Что должно заработать

Существующая DEV-панель становится Scene Composer и подключается к config store из таска 01. Панель остаётся development-only и сохраняет текущие действия запуска, паузы, скорости, playhead, seek, выбора/рестарта сцены, диагностики и media controls. Настройки разделены на Global и сцены 00, 00.1, 01; для 02–09 новых художественных настроек нет. Контролы имеют диапазоны, preview, presets/reset, JSON import/export и безопасно работают с реальным film clock и действующей конфигурацией.

## Критерии приёмки

- [x] Контролы сгруппированы по Global и 00/00.1/01, имеют русские понятные названия, единицы измерения и проверяемые min/max; значения применяются к общему config store без независимых scene clocks.
- [x] Существующие play/pause/speed/playhead/seek/scene launch controls продолжают работать; добавлены restart выбранной сцены, актуальный seek range, минимум два именованных сравнимых пресета и reset параметра/сцены.
- [x] JSON экспортирует активный config. Import валидирует структуру/версию, принимает partial JSON, безопасно обрабатывает неизвестные/ошибочные поля и сохраняет ранее активную конфигурацию, если документ нельзя разобрать.
- [x] Global quality/DPR подсоединены к существующему FilmCanvas; второй renderer/canvas не создаётся. Изменения DPR соблюдают допустимые device bounds.
- [x] Шрифт художественного текста выбирается без reload; UI дождётся существующего font-loader перед переключением. DEV-панель отсутствует в production build.
- [x] Focused tests проверяют control-to-store mapping и import/export/reset/presets; `npm run check` проходит либо зафиксирован точный блокер.
