## Что должно заработать

Общее основание для всех трёх начальных сцен: typed schema v1, неизменяемые defaults, user overrides, нормализация JSON по каждому полю, один наблюдаемый config store и локальная типографическая библиотека. По умолчанию художественный текст использует Marck Script; все четыре выбранных family локальны и проверены для русской кириллицы. Сайт читает `/scene-composer.json` при старте как optional override и использует существующий preload/offline pipeline, не блокируя фильм при отсутствующем или ошибочном файле.

## Из брифа, дословно

> «Основной художественный рукописный шрифт — **Marck Script**.»
> «Шрифт должен быть локальным ресурсом, включённым в систему предзагрузки и офлайн-кэш.»
> «Если шрифт требует дополнительной загрузки, она должна завершиться до его применения.»

## Критерии приёмки

- [x] Config типизирован, версия `schemaVersion: 1`, defaults отделены от пользовательского значения; отсутствующие поля получают defaults, известные неверные поля безопасно возвращаются к default, неизвестные поля не попадают в активную модель.
- [x] `/scene-composer.json` читается при запуске как optional same-origin ресурс; частичный файл merge-ится с defaults; отсутствующий/битый JSON оставляет defaults и не меняет реальный preload success/progress.
- [x] Marck Script, Bad Script, Caveat и Cormorant Garamond доступны как локальные ресурсы с корректной русской кириллицей и «Ё/ё»; внешние font-запросы не выполняются.
- [x] Смена face ожидает его загрузку до применения; AssetManager/runtime manifest и offline cache включают файлы шрифтов и корректно обрабатывают optional startup config.
- [x] Unit tests покрывают defaults, partial merge, malformed/unknown inputs, границы полей и выбранные glyph coverage; `npm run check` проходит либо отмечено точное объяснение блокера.
