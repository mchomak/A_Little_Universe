## Что должно заработать

Сцена 00 показывает художественные настройки, не меняя реальный progress. Сцена 00.1 становится аккуратным Minimal Luxury / Cinematic Editorial экраном, сохраняет смысл текстов и точную consent/media-последовательность. Единственная точка света закреплена в экранном центре и остаётся тем же визуальным объектом, когда `Открыть подарок` переключает приложение из готовности в пролог. Root DEV panel доступна для запуска/настройки scenes 00 и 00.1, не дублируя бизнес-логику.

## Критерии приёмки

- [x] Экран 00.1 реализует заданный тёмный editorial стиль, тонкие разделители/карточки, читаемую иерархию, согласованные переключатели/иконки/кнопки и мягкое появление; обычный emoji заменён собственным нежно-розовым SVG-символом четырёхлучевого света.
- [x] Подписи «выкл» удалены; responsive компоновка и касания читаемы на iPad в landscape/portrait с safe areas. Motion учитывает `prefers-reduced-motion`.
- [x] `Open Gift` не вызывает скачка точки: один app-level point view остаётся в normalized `(0.5, 0.5)`, не меняет размер/яркость и не зависит от remount Canvas. Resize/orientation не сдвигает её.
- [x] Scene 00 применяет Composer-параметры glow/count/movement/collapse только к визуализации; фальсифицированного progress нет.
- [x] Permission request остаётся только по существующему явному действию; согласия, проверка устройства, recording/recovery и статусы недоступных gaze/upload остаются реальными и не имитируются.
- [x] DEV-панель видна в DEV при загрузке/подготовке и продолжает запускать отдельные сцены. Проверки для отказа/отсутствия media API не инициируют permission request.
