## Что должно заработать

Слепая приёмка G4 показала два несоответствия прямому брифу: composer 00.1 настраивал только шрифт, интервалы и появление, без дополнительных визуальных CSS параметров; Composer показывал возврат частиц 75%, хотя renderer использовал 15%. Закрыть оба расхождения малыми изменениями общей schema и существующих владельцев сцены.

## Из брифа, дословно

> «Сцена 00.1: типографика, интервалы, длительность появления элементов, визуальные параметры интерфейса.»
> «Сцена 01: … доля частиц, возвращающихся к точке …»
> «Изменение параметров через контролы с понятными названиями и допустимыми диапазонами.»

## Разделы спецификации

§6 группы параметров, воспроизведение/live preview, schema/defaults; §7 performance; §9 проверки; §10 acceptance.

## Критерии приёмки

- [x] 00.1 получает небольшое число schema-backed параметров для художественной типографики и визуального вида карточек (например, масштаб текста/межстрочный интервал и непрозрачность поверхности); defaults сохраняют нынешнюю композицию и контраст, значения имеют диапазоны и сброс.
- [x] Контролы 00.1 отображают реальные единицы, мгновенно меняют уже открытую сцену и не ломают адаптивную компоновку или safe areas в portrait/landscape.
- [x] Контрол возврата частиц показывает фактическую долю, которую использует renderer (по умолчанию 15%, допустимый диапазон 0–20%), а конфигурация и техническая документация явно объясняют нормализованный field 0–1 (коэффициент от допустимого максимума 20%). Не менять schema v1 без необходимости; UI показывает фактические проценты. JSON/defaults и UI mapping согласованы.
- [x] При работающем WebGL fallback «3D-сцена недоступна» не остаётся в accessibility tree; при реальной недоступности WebGL сообщение остаётся видимым/доступным.
- [x] Изменения не трогают визуальное/функциональное поведение сцен 02–09, не меняют consent, preload progress, permissions, recording, или transition в сцену 02.
- [x] Добавлены assertion-level тесты для defaults/partial JSON, отображаемых диапазонов и применения CSS custom properties; reset возвращает values к defaults.
- [x] Технические документы и storyboard v2.0 согласованы с фактическими Composer параметрами.
- [x] Browser проверка 00.1 и Composer в 1024×768 и 768×1024; `npm run check` проходит. Физический iPad не заявлять тестированным.

## Границы

Не добавлять новые зависимости, отдельный Composer, renderer, canvas или новые пользовательские настройки вне 00.1/01. Не менять render fallback при реальной недоступности WebGL; устранить только ложное объявление недоступности при успешно работающем canvas.


## Результат

Schema v1 расширена настройками 00.1 (`typeScale`, `lineHeight`, `cardOpacity`); возврат частиц отображается фактическими 0–20% (default 15%). Ложный WebGL alert скрыт при успешном canvas. Браузерные проверки прошли в 1024×768 и 768×1024; `npm run check` — 83 теста / 23 файла, ESLint, оба typecheck и production build прошли. Commit: `fa9682c`. Физический iPad не проверялся.
