# Спецификация

Данные: явный список ID из брифа; искать поддерживаемые изображения в корневых images, без перемещения исходников. Стабильная числовая сортировка 1–4 с устойчивым fallback, до четырёх фото; папки отсутствующие и пустые пропускаются согласно более позднему указанию. Пока событий нет, сохранить явно временную демонстрационную галерею, чтобы навигация и переход не ломались. JSON caption по ID, существующие тексты только при достоверном соответствии. Сцена: динамическая длина, чередование слева/справа, фокусированный коллаж [4] над [2][1][3], дополнительные фото появляются из частиц, без пустых рамок и текста. Камера/свет/переход остаются прежними. Тесты, затем commit/push в текущую ветку.
