# Спецификация

Настроить изолированные значения галереи и цвет пола, сохраняя существующие геометрию, компоновку и общие системы. Старые явно сохранённые значения не заменять; отсутствующие поля получают новые defaults. Проверить тестами, сборкой и по возможности визуально относительно K05-01–04.

# Допущение

Палитра defaults меняется для новых или неполных конфигураций; явно сохранённые значения имеют приоритет.
