## Что должно заработать

Полный JSON Scene Composer импортируется только после завершения всех проверок и подготовки вспомогательных ресурсов. Если JSON неверен или необязательная проверка не прошла, глобальная конфигурация остаётся без изменений; успешный импорт обновляет store один раз.

## Из брифа, дословно

> «Отсутствие частичного повреждения конфигурации при неудачном импорте.»
> «Не заменяй автоматически текущие сохранённые настройки дефолтными значениями.»
> «Перед любыми изменениями схемы зафиксируй существующий формат и, если необходимо, реализуй безопасную миграцию.»

- [x] Все валидации/асинхронные проверки выполняются до `updateConfig`; неудачный импорт не вызывает store update и не меняет ни одного параметра.
- [x] Успешный импорт схемы v26 и поддерживаемых старых версий выполняет одно обновление после полной подготовки; дополнительные и отсутствующие поля обрабатываются нормализатором без сброса текущих настроек.
- [x] Автотесты покрывают успешный импорт, ошибочный JSON, неподдерживаемую версию и отказ подготовки шрифта, используя только тестовую config.
- [x] Внутренние config IDs и defaults неизменны; настоящие пресеты и Electron/macOS код не затронуты.
