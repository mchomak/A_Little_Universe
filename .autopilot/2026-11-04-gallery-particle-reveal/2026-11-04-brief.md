# Галерея — коллажи: появление доп. фото из частиц + постепенное проявление

Продолжаем текущую работу над коллажами в галерее.

Сейчас базовая механика коллажей уже пишется, но **пока без `memory-signal-threejs` и без последующего проявления фото**. Нужно доработать это.

## Задача

Для событий, где у одной точки галереи есть **2–3 дополнительных фотографии**, сделай следующую механику:

### 1. Состояние по умолчанию
- Дополнительные фото **не видны**.
- Видна только основная фотография в рамке.

### 2. При фокусе на основное фото
- Рядом с основной фотографией начинают появляться дополнительные фото.
- Их появление должно идти **сначала в виде частиц**, используя подход / алгоритм из `memory-signal-threejs`.
- Не нужно просто делать fade-in прямоугольников. Сначала должно быть ощущение, что фото собираются из светящихся частиц.

### 3. После сборки из частиц
- Дополнительные фото должны **не просто резко заменяться оригиналом**, а **постепенно проявляться** в нормальное изображение.
- Для этого переиспользуй или адаптируй тот же подход, который у нас уже реализован для **проявления оригинального фото из частиц в сцене 04**.
- То есть:
  - сначала видна particle-версия;
  - затем под ней / поверх неё начинает плавно проявляться реальное фото;
  - частицы постепенно уходят или растворяются;
  - в итоге остаётся обычное фото.

### 4. При выходе из фокуса
- Дополнительные фото должны аккуратно исчезать.
- Можно либо:
  - сначала снова частично “рассыпать” их в частицы и убрать,
  - либо сделать мягкое исчезновение, если это выглядит чище и стабильнее.
- Главное — без резких скачков.

## Что использовать

### memory-signal-threejs
Используй `memory-signal-threejs` как основу / референс для:
- генерации photo-particles из изображения;
- мягкого движения частиц;
- параметров размера, шума, глубины и свечения.

Но **не тащи весь репозиторий как отдельное приложение**. Нужно встроить только нужную логику в текущую архитектуру сайта.

### Сцена 04
Переиспользуй / адаптируй текущую реализацию **проявления фото из частиц**, которая уже есть или пишется для сцены 04:
- не дублируй логику без необходимости;
- если можно, вынеси общее решение в переиспользуемую утилиту / компонент / контроллер.

## Важные требования

- Не ломать уже написанную механику галереи и фокуса.
- Не создавать отдельный canvas или отдельный renderer.
- Всё должно работать внутри текущей Three.js-сцены и существующей системы галереи.
- Не ломать производительность: одновременно активны только фото текущего выбранного коллажа.
- Не запускать particle-эффект сразу для всех фото галереи.
- Если в одном событии 2–3 фото, они могут появляться:
  - либо одновременно,
  - либо с небольшим красивым stagger по времени.
- Сохранять читаемость композиции: доп. фото не должны хаотично перекрывать основное.
- Если для некоторых фото эффект выглядит плохо, сделай возможность отключить particle-режим на уровне конфигурации конкретного коллажа.

## DEV / настройки

Если это уместно, добавь несколько настроек в DEV-панель:
- particle count / density;
- particle size;
- noise strength;
- z-depth / relief;
- длительность сборки;
- длительность проявления в обычное фото;
- stagger delay между дополнительными фото.

Но не перегружай панель лишним.

## Проверка

Проверь:
1. фокус на основное фото;
2. появление 2–3 дополнительных фото из частиц;
3. плавное проявление в обычные изображения;
4. стабильную работу при повторном входе/выходе из фокуса;
5. отсутствие утечек объектов / дублирования / зависших particle-систем;
6. производительность и корректность в текущей галерее.
