## Что должно заработать

Разработчик может настраивать плотность, размер, шум, рельеф, свечение и обе длительности анимации, а также stagger в одной свёрнутой DEV-группе. Для любого устойчивого event id можно отключить particle режим, сохранив мягкое появление самого изображения.

## Из брифа, дословно

> «Если для некоторых фото эффект выглядит плохо, сделай возможность отключить particle-режим на уровне конфигурации конкретного коллажа.»
> «Если это уместно, добавь несколько настроек в DEV-панель:»
> «Но не перегружай панель лишним.»

## Разделы спецификации

Истории 5, 6 и 8; «Решения по реализации»; границы `galleryCollageConfig`, `SceneComposerConfig` / DEV.

## Критерии приёмки

- [ ] В существующем Scene Composer добавлены восемь настроек с дефолтами/границами из spec; новые значения переживают normalize, save/import/export, reset и старый schema migration.
- [ ] В DEV-панели есть одна свёрнутая секция; значения меняются без React update на кадр и применяются к particle uniforms/timeline; изменение плотности перестраивает только выбранное событие.
- [ ] Небольшая per-event конфигурация адресуется стабильным event id, по умолчанию включена; выключенный режим показывает мягко проявившуюся обычную фотографию без Points system.
- [ ] Unit-тесты покрывают defaults/clamping/migration/reset и event-id opt-out; `npm run check` проходит.
- [ ] Изменения закоммичены и отправлены в текущую ветку без merge в `main`; ранее работавший локальный сайт перезапущен на актуальной сборке; финальный отчёт называет файлы, параметры, поведение и URL.
