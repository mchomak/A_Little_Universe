# Runtime assets

Здесь появятся только используемые приложением оптимизированные ассеты. Импортировать из TypeScript через Vite, чтобы получать хешированные URL. Для файлов с фиксированными URL при необходимости создать `frontend/public/assets/`.

Сейчас внешних ассетов нет: сфера — геометрия Three.js, шрифты системные. Референсы из `references/keyframes/` автоматически сюда не копируются.
