# Графические системы

Место для реально переиспользуемых GPU-систем: буферы частиц, морфинг, материалы. Добавлять при реализации конкретного кадра; не обновлять React state для отдельных частиц или каждого кадра. Система владеет созданными ею ресурсами и освобождает их при завершении. Сейчас таких систем нет.
