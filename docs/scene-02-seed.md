# Сцена 02 — формирование, падение и пробуждение семечка

Текущий проход реализует бриф от 2026-10-30 и направление кадров `key_frames/S02_F01_SeedFormation.png`, `S02_F02_SeedFall.png`, `S02_F03_SeedAwakening.png`. Картинки остаются художественными референсами, в runtime не загружаются. Последующий рост Lily остаётся явно схематическим placeholder; GLB и клипы роста/раскрытия ещё не подключены.

| Локальное время | Действие |
|---|---|
| 0–2,8 с | Частицы постепенно возникают, движутся по небольшим орбитам и сходятся к центру. Жемчужно-золотистая оболочка с розовым оттенком и прожилками набирает объём |
| 2,8–4,45 с | Падение с квадратичным ускорением до самого удара. Короткий след отстаёт по той же траектории; камера начинает снижаться в 3,12 с |
| 4,45–5,30 с | Контакт в центре уже видимых золотых колец, распад оболочки за 0,12 с, короткие баллистические искры и расширяющаяся световая волна |
| 4,45–4,73 с | В центре проявляется небольшой выпуклый бугорок, который остаётся основанием цветка |
| 4,95–6,65 с | Через 0,5 с после контакта начинает плавно проявляться холодный свет сверху: локальный spotlight, мягкий световой столб и пятно на плоскости |
| 5,65–6,4 с | Передача существующему placeholder ростку, вес 0→0,065 |
| 6,4–18 с | Рост placeholder до полного размера |
| 18–23 с | Удержание; далее прежнее ожидание касания бутона в сцене 03 |

## Реализация

`TIMING.growth` в `frontend/src/engine/filmConfig.ts` задаёт все границы. `scenes/growth/seedProcedure.ts` вычисляет позы и детерминированные GPU seeds. `GrowthScene.tsx` собирает геометрию и обновляет refs/uniforms через существующий `useSceneAnimation` и канонический `FilmRuntime`. Нет независимого таймера, симуляции с накоплением состояния или React state на каждом кадре.

Оболочка — объёмная lathe-геометрия с заострёнными концами, полупрозрачными прожилками, мягким ядром и ограниченным локальным ореолом. Полная высота — около 11% высоты вида (существенно больше прежнего 1,7%). Размер пересчитывается из актуального viewport/FOV, включая поворот устройства во время паузы. `seedY` обозначает падение точки контакта; центр оболочки смещён вверх на её полувысоту, поэтому нижний кончик достигает плоскости ровно в момент удара.

`seedShaders.ts` содержит локальные шейдеры оболочки, ядра, ореола, горизонтальных колец, лунного света и трёх particle batches. Орбиты, след и искры вычисляются на GPU из абсолютного времени. Standard/low: 76/28 орбитальных частиц, 30/12 точек следа, 110/38 искр; оболочка 64/32 радиальных сегмента. Кольца лежат на world XZ и получают перспективное сжатие от камеры; `fwidth` сглаживает линии под острым углом. Новых текстур, зависимостей и postprocessing нет.

`CameraDirector` использует чистую `getGrowthCameraPose`: задержка сопровождения 0,32 с, снижение на 0,42 world units без приклеивания семечка к центру экрана. После 6,4 с камера плавно возвращается к прежней позе входа в сцену 03. Reduced motion сохраняет фронтальную камеру на протяжении всей сцены, убирает вращение, пространственные орбиты, след, искры и ударную волну, сохраняя формирование, падение, кольца, бугорок и мягкое появление света.

Shader uniforms сохраняют ссылки при смене качества и DPR. Геометрия и материалы принадлежат R3F-дереву и освобождаются при размонтировании; дополнительные render loops, listeners и media resources не создаются. Один постоянный Canvas и прежние gates фильма сохранены. В сцене 02 скрыта техническая верхняя подпись, фон нижней панели прозрачен, чтобы панель не обрезала кольца; управление паузой и качеством остаётся доступным.

## Контракт будущей модели

`getGrowthHandoff(time, viewportHeight?, reducedMotion?)` возвращает `{anchor, stage, localTime, weight}`. Anchor — `[0, -1.45, 0]`, +Y, identity rotation, единица Three.js. В 6,4 с `localTime=0,75`, `weight=0,065`; к 18 с вес равен 1. Модель должна расти из этого центра. Нормализация будущей GLB и длительность её clips остаются отдельной задачей.

Переход из пролога сохраняет существующий `PersistentLight`: DOM-свет затухает за 1,15 с, а сценическое ядро принимает свет с противоположным весом. Новый interaction gate не добавлен. DEV Timeline содержит отдельные отметки формирования, падения, удара, начала лунного света, передачи росту и завершения.

## Проверка 2026-10-30

- `npm run check`: ESLint, 200 тестов в 52 файлах, strict TypeScript и production build прошли. Существующие предупреждения Three.js CommonJS, Vite native config и chunk >500 kB остаются.
- Тесты проверяют ускорение до контакта, задержку и непрерывность камеры, reduced-motion переход в сцену 03, увеличение размера, кольца до удара, распад и срок жизни искр, бугорок, задержку света, handoff, обратный seek и воспроизводимые particle seeds.
- Chrome: просмотрены кадры 0,9 / 2,65 / 4,25 / 4,6 / 5,1 / 6,65 с при 1024×768 и семечко при 768×1024. Проверены пауза, обратный seek, standard/low и reduced motion. Один Canvas; число GPU-геометрий стабилизируется после пересоздания сцены. Повторный seek сохраняет позу и uniforms; побайтовое совпадение WebGL PNG не заявляется из-за небольших различий сглаживания на краях.
- Physical iPad/Safari, производительность на реальном планшете и одновременная запись реакции этим проходом не проверялись.
