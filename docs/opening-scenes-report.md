## Фактический пролог

| Время | Поведение по default config |
|---|---|
| 0–3 с | Постоянная Ivory White точка остаётся в центре viewport и мягко пульсирует. |
| 3–7 с | Над точкой глиф за глифом раскрывается «Я долго думал, что тебе подарить…». |
| 10–14,8 с | Ниже точки раскрывается «И решил, что ты заслуживаешь чего-то особенного:»; первая фраза остаётся видима. |
| 14,8–16 с | Обе фразы удерживаются вместе. |
| 16–21 с | Обе строки растворяются, частицы берут старт из маски реальных глифов. |
| после 21 с | Остаются только точка и «Прикоснись к свету»; film clock ждёт касания без ограничения. |

Касание запускает текущий 0,3-секундный transition в сцену 02. Световая точка — один app-level объект, который сохраняется между состояниями ready и prologue. Фразы позиционируются с измеренным зазором вокруг точки, с reflow при смене шрифта и размеров viewport. Прологовый default использует локальный Marck Script. В standard quality настроено 1 800 частиц; low quality уменьшает их количество вдвое. Seed и scene time дают воспроизводимый seek/replay.

## Scene Composer и конфигурация

DEV-панель содержит Global controls и группы 00, 00.1, 01; в 00.1 доступны live масштаб и межстрочный интервал заголовка, а также непрозрачность карточек. Общие controls позволяют выбрать/запустить сцену, restart, pause и seek. Для художественных параметров доступны reset, два пресета, import/export JSON. В production интерфейс Scene Composer отсутствует.

Production override — необязательный same-origin JSON в корне сайта: /scene-composer.json. Schema version 1 хранит только отличия от defaults. `particleReturnFraction` — коэффициент `0–1` от лимита renderer `20%`; default `.75` соответствует фактическим `15%`, которые Composer показывает как проценты `0–20`. Если файла нет или он невалиден, фильм использует defaults и preload не блокируется. Локальные шрифты Marck Script, Bad Script, Caveat и Cormorant Garamond включены в сборку; набор требуемых кириллических глифов содержит Ё/ё. Подробности и пример формата — в [README](../README.md) и [архитектуре](architecture.md).

## Ограничения

Трекер взгляда, музыка, личные фотографии и защищённый upload не подключены. Запись реакции условная и хранится локально; browser storage может быть очищен, а экспорт лишь запрашивает сохранение у браузера. Сцены 02–09 не проходили художественную переработку.

Production build сообщает о JavaScript chunk более 500 kB после минификации (App chunk 687.39 kB, 195.04 kB gzip); лимит не повышался. В тестах также остаётся предупреждение Three.js о deprecated CommonJS require. WebGL context loss показывает fallback; восстановление текущего кадра не реализовано.
