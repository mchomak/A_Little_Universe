# Lily model full-height captures

Orthographic Blender Workbench overview captures, 1000 × 1400 px. These are neutral geometry previews, not final material renders. Each source `.blend` was opened in a separate background Blender process; temporary camera/render settings were not saved to any source file.

The `45deg-above` set uses a 45° azimuth and approximately 30° elevation to show into the flower heads.
