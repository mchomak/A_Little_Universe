# ADR 0016: Сохранить wire format пользовательского пресета

## Контекст

Пользовательские пресеты уже сохранены в формате отдельного `ScenePresetV1`. Обновление DEV-панели должно добавлять проверку и импорт без перезаписи существующих значений или принудительного преобразования файлов.

## Решение

Оставить `formatVersion: 1`, номер снимка в `configSchemaVersion`, существующие scope IDs и поле `scene`. Парсер принимает текущую schema v26 и поддерживаемые старые версии 1–26, а будущую неподдерживаемую версию отклоняет до применения. Отсутствующие свойства старого снимка сохраняют текущие значения; дополнительные envelope-поля безопасно игнорируются после проверки документа, а значения конфигурации проходят существующую нормализацию.

## Почему

Новый формат потребовал бы миграции и затронул бы сохранённые файлы без необходимости менять сам контракт. Молчаливое принятие будущей схемы не гарантирует правильное толкование её полей. Заполнение отсутствующих свойств defaults могло бы затереть пользовательские значения. Явная поддержка существующего диапазона сохраняет совместимость и задаёт безопасный отказ для неизвестного будущего формата.

## Последствия

Ранее созданные пресеты остаются доступными без массовой перезаписи. Изменения схемы конфигурации требуют сохранять номер снимка и, если совместимости недостаточно, добавлять явную безопасную миграцию. Неподдерживаемый документ не меняет конфигурацию частично.
