## Контекст

Production может получать художественные overrides из локального JSON, но приложение должно сохранять offline-ready запуск.

## Решение

Startup JSON является optional same-origin ресурсом; отсутствие файла или ошибка загрузки не блокируют готовность фильма.

## Почему

Обязательный файл или удалённый источник сделали бы запуск зависимым от доступности ресурса или сети и нарушили бы offline-ready путь.

## Последствия

При недоступном JSON фильм запускается с defaults. Production overrides должны быть доступны как same-origin ресурс.
