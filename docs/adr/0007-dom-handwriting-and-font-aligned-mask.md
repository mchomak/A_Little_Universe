## Контекст

Текст пролога должен выглядеть как связная рукописная фраза, а частицы распада — совпадать с пикселями выбранного шрифта, в том числе при переносе строки на узком экране. Отдельные глифы и растровая картинка как видимый текст дают другие границы для анимации и синхронизации текста с частицами.

## Решение

Оставить надписи DOM-слоем цельной строки и раскрывать их общей мягкой горизонтальной маской. Для маски частиц использовать альфа-пиксели локального активного художественного шрифта: Marck Script по умолчанию, а при выборе другого шрифта в Composer — выбранное начертание. Растрировать строки с учётом фактического расположения строк; при неготовом шрифте использовать существующий fallback.

## Почему

Цельная DOM-строка сохраняет соединение глифов при имитации письма, а маска из текущего начертания удерживает визуальное совпадение частиц и надписи. Это также позволяет оставить коллаж ориентиром для последовательности кадров, не превращая его в runtime-изображение.

## Последствия

Расположение строк и готовность шрифта становятся входными условиями для маски. Изменение шрифта или переносов требует строить маску заново так, чтобы частицы оставались совмещены с видимым текстом.
