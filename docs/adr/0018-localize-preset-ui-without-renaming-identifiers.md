# ADR 0018: Локализовать подписи, сохраняя технические идентификаторы

## Контекст

Пользовательские подписи DEV-панели и preset controls должны быть на русском, при этом внутренние ключи, scope IDs, enum-значения, uniforms, API и JSON уже используются конфигурацией и сохранёнными пресетами. Вложенный Review Notes UI также отображается в DeveloperPanel.

## Решение

Переводить отображаемые DOM-метки и текст, включая заголовки и статусы Review Notes, не меняя технические идентификаторы и значения enum. Review Notes входит в область перевода T03; его status values и API поведение остаются прежними.

## Почему

Переименование внутренних ключей и enum ради русского интерфейса нарушило бы сериализованные данные и связи API без пользы для оператора, который видит только подпись. Исключение Review Notes оставило бы часть видимой DEV-панели на другом языке. Отображаемая подпись отделяет интерфейсный язык от стабильного контракта данных.

## Последствия

Русские подписи должны задаваться на уровне отображения, а существующие JSON и внутренние значения остаются совместимыми. При добавлении видимых компонентов панели их пользовательский текст входит в локализацию, тогда как API и status values остаются техническим контрактом.
