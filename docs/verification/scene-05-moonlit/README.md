Browser inspection reported zero console errors; the existing `THREE.Clock` deprecation warning remains. A requestAnimationFrame sample observed 120 callbacks/s with an 8.5 ms p95 callback interval. This is browser callback timing, not measured GPU/WebGL FPS, and is not a physical iPad performance measurement. Sustained device performance and iPad/Safari behavior remain unverified.
