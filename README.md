# A Little Universe for You

Приватный интерактивный 3D-подарок для Василисы. История ведёт от света и семени через лилию, личные фотографии и галерею к галактике, поздравлению и финалу.

## Целевая платформа

Фильм запускается локально на MacBook с Apple M2 и экраном около 15 дюймов. Цель — максимальное практичное качество графики и разрешение экрана этого компьютера. Для рендеринга нужен современный браузер с WebGL2 и аппаратным ускорением; WebGPU не требуется.

## Состояние проекта — 6 ноября 2026

Основная ветка `main` содержит полностью проходимый маршрут сцен 00–09. Техническая готовность не означает, что все сцены уже соответствуют финальному художественному сценарию.

| Этап | Что реализовано в `main` |
|---|---|
| 00 · Загрузка | Preload, проверка и загрузка ресурсов. Production-сборка включает манифест и Service Worker для автономной загрузки. |
| 01 · Пролог | Рукописные фразы, свет, GPU-распад букв на частицы и ожидание касания. Текущий gate — 18 секунд. |
| 02 · Семя и рост | GPU-формирование и падение семени с передачей анимированной модели Lily 004; световой импульс и локальные частицы роста синхронизированы с анимацией Lily и настраиваются в DEV Scene Editor. |
| 03 · Раскрытие | Та же Lily 004 автоматически раскрывается после короткой паузы в конце роста. |
| 04 · Портрет из вихря | Раскрытая Lily 004 растворяется в восходящий вихрь; часть тех же частиц собирается в звёздный портрет. Слот сцены — 34 секунды. |
| 05 · Галерея | Интерактивное исследование карточек и переход между воспоминаниями. Подключена одна настоящая фотография; остальные 11 карточек — явно временные development placeholders. |
| 06 · Глаз | Навигационный placeholder. Отслеживание взгляда не подключено. |
| 07–09 · Галактика и финал | Процедурная GPU-галактика сохраняется фоном в следующих сценах. Поздравление и финальная навигация работают; личное письмо и музыка ещё не добавлены. |

Storyboard v3.0 остаётся источником художественных требований, но часть текущей реализации ещё не приведена к нему. Сцена 04.1 пока процедурная; некоторые личные материалы заменены placeholders. Сверяйте сюжет и keyframes с [актуальным storyboard](A_Little_Universe_for_Vasilisa_Storyboard_v3.0.md) и [индексом ключевых кадров](references/keyframes/README.md).

## Локальный запуск

Требуется Node.js 22.12+ в ветке 22 или Node.js 24+, а также npm. Запустите из корня проекта:

```sh
cd frontend
npm ci
npm run dev
```

Откройте <http://127.0.0.1:5173>. Vite привязан к локальному компьютеру; отдельный сервер для просмотра не нужен. Порт строгий: если 5173 занят, запустите `npm run dev -- --port 5174`.

Чтобы проверить production-сборку:

```sh
npm run build
npm run preview
```

Preview будет доступен на <http://127.0.0.1:4173>. Offline-подготовка проверяется только в production-сборке; dev-сервер не обещает автономную загрузку.

## Управление и разработка

- Пролог ждёт прикосновения или клавиатурной активации; затем рост и раскрытие лилии идут автоматически. Галерея управляется кнопками и жестами.
- DEV Scene Editor открывается кнопкой DEV в development или локально в production preview по адресу `http://127.0.0.1:4173/?debug`. Он включает Timeline, Inspector, настройку качества и DPR, заметки и A/B-сравнение; без `?debug` панель скрыта.
- Iris Visual Lab доступен в development по адресу `/dev/iris-lab`; описание — в [документации лаборатории](docs/iris-visual-lab.md).
- Очередь музыки галереи и пути к трекам редактируются в [galleryMusicPlaylist.json](frontend/src/data/galleryMusicPlaylist.json); порядок в JSON — порядок воспроизведения. `artist` и `gain` необязательны (`gain` по умолчанию 1). Для исходного имени MP3, отличающегося от имени в `assetPath`, укажи `sourceFileName`. Между всеми музыкальными переходами исходный трек затихает, выдерживается секунда тишины, затем следующий плавно набирает громкость.
- Конфигурация сцен использует schema v24, принимает версии 1–24 и сохраняет безопасные значения по умолчанию. Подробности — в [справке Scene Composer](frontend/src/systems/scene-config/README.md).
- Общие правила архитектуры и добавления сцен описаны в [docs/architecture.md](docs/architecture.md).

## Непрерывность фона и окружения сцен 02–04

`PhoneBackground` остаётся DOM-слоем и рассчитывает кроп по времени падения семени из `FilmRuntime`; `getPhoneBackgroundProgress` общий для движения фона и opacity `GrowthSky`. `SceneDirector` очищает сохранённый `THREE.Scene.background` при входе в пролог и сцены 02–04, чтобы был виден DOM-фон, и владеет единственным `GrowthSky` на всём переходе 02–04. При прямом входе в сцены 03/04 небо сразу получает установившееся ночное состояние.

Остров, облачное море и лунный свет из `GrowthScene` сохраняются через сцену 03 и начало сцены 04. `GrowthClouds` и `GrowthSky` обновляются по `FilmRuntime`; облачные материалы и shader-uniforms меняются напрямую, без покадрового React state. В начале сцены 04 перенесённое окружение плавно затухает через `environmentOpacity`.

Проверки frontend запускаются из `frontend/`:

```sh
npm run check
```

Команда выполняет ESLint, тесты, строгую проверку TypeScript и production build. Полная проверка 6 ноября 2026 года прошла успешно: 788 тестов в 135 файлах, lint, typecheck и build.

## Приватность и незавершённые функции

- Gaze tracking и отправка видео на сервер не подключены.
- При загрузке браузер запрашивает разрешение камеры и микрофона. Если доступ разрешён, локальная запись реакции начинается вместе с фильмом и сохраняется в IndexedDB; при отказе фильм идёт без записи. Камера не используется для распознавания личности.
- Backend необязателен и пока предоставляет только `GET /health`; он не принимает видео и не участвует в просмотре.
- Личные фотографии, финальные подписи и письмо нужно добавить вместо временных материалов. В runtime используется первая фотография `frontend/src/assets/start_img.jpg`.

Запустить необязательный backend можно из `backend/` через `uv sync --frozen --extra dev`, затем `uv run uvicorn app.main:app --host 127.0.0.1 --port 8000`. Проверка: <http://127.0.0.1:8000/health>.
